## Модель в двух абзацах

Плагин — это папка с `plugin.json` и `index.js`. Чистый ESM, без сборки, без `node_modules`. Ядро не содержит ни редактора, ни терминала, ни проводника: всё это плагины. Ядро даёт им реестр команд, шину событий, раскладку и мост к ОС.

Плагин получает `PluginContext`: команды, события, слоты UI, хранилище, IO-порты, capability-контракты и сервисы ОС (`core.fs`, `fs.tools`, `pty`, `proc`, `serial`). Всё, что возвращает `Disposable`, кладётся в `ctx.subscriptions` и освобождается при выгрузке плагина автоматически.

```
плагин = папка + plugin.json + index.js
```

---

## Три правила, которые объясняют почти всё

1. **Всё есть плагин.** Не нравится редактор — выкинь и поставь другой.
2. **Всё, что возвращает `Disposable`, — в `ctx.subscriptions`.** Иначе утечка.
3. **`index.js` — один файл.** Относительные импорты не работают: модуль грузится через blob-URL.
